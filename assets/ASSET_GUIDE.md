# PixelVault assets

- `images/brand/`: user-provided logo, wordmark and illustrations.
- `icons/3d/icons/`: supplied 3D icon crops; currently used for feature tiles where available.
- `icons/svg/`: remaining SVG icon references.
- `icons/3d/pixelvault_3d_icon_board.png`: visual reference board; not used as an app icon.

The image crops are individual image files, not vector assets or transparent 3D render models.
